Support & Troubleshooting

Got a question or running into an issue? Here is how to get the most out of the extension.

Keyboard Cheat Sheet

LinkedIn Rich Text Shortcuts enables standard formatting keystrokes based on your operating system:

Platform Shortcut Action
macOS Cmd + B Toggle bold on selected text
Windows Ctrl + B Toggle bold on selected text
Linux Ctrl + B Toggle bold on selected text
Remove Bold (All) Ctrl/Cmd + B Select bolded text and press shortcut again to remove bold

Troubleshooting Checklist

If the shortcut does not seem to trigger bold formatting on LinkedIn, work through these simple verification steps:

1. Refresh the LinkedIn Tab

When you install or update a Chrome extension, Chrome does not retroactively inject scripts into tabs that were already open. Simply press F5 (or Cmd + R on Mac) on your active LinkedIn tab once.

2. Ensure Text is Highlighted

The extension formats your current text selection. Click and drag your cursor over the word or sentence you want to bold before pressing the shortcut.

3. Confirm the Extension is Enabled

Open Chrome and navigate to chrome://extensions in your address bar. Verify that the toggle switch next to LinkedIn Rich Text Shortcuts is turned on.

4. Check for Shortcut Conflicts

On Windows, pressing Ctrl + B in a standard browser tab sometimes toggles Chrome's Bookmarks bar. Our content script suppresses this default behavior whenever you are focused inside a LinkedIn text field. If another third-party extension (such as a password manager or custom keybinder) intercepts Ctrl+B before the page receives it, try temporarily disabling that conflicting extension to test.

5. Unsupported Fields

LinkedIn supports rich text formatting in post composers, comment boxes, and reply threads. Plain text inputs (such as profile headline editors or search bars) do not support bold styling natively on LinkedIn.

Note on Italics and Underline: LinkedIn's rich text editor does not support native italic or underline styles. The extension intentionally avoids adding these shortcuts to prevent generating broken, inaccessible Unicode characters.
