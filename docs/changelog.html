Changelog & Updates

All notable product enhancements, architectural upgrades, and bug fixes.

Version 2.0.0 November 13, 2026

Major Rebuild: macOS Support & Manifest V3

Version 2.0.0 is a complete architectural rebuild of the extension, bringing first-class Mac support, Google Manifest V3 compliance, and a modern DOM selector engine.

Added

  • Native macOS Shortcut Support: Added native Cmd + B keyboard handling for Mac users alongside Ctrl + B for Windows and Linux.
  • Manifest V3 Specification: Rebuilt the extension under Google's modern Manifest V3 platform with an ephemeral background service worker.
  • High-Resolution Icons: Modernized brand icon assets rendered at 16x16, 32x32, 48x48, and 128x128 pixels for crisp display on high-DPI and Retina monitors.
  • Browser Toolbar Action: Clicking the extension icon in the Chrome toolbar opens the official Chrome Web Store listing for one-click reviews and documentation.
  • Automated Test Suite: Added comprehensive multi-platform test coverage running under the Bun test runner.

Changed

  • Resilient DOM Detection: Upgraded editor detection to support modern LinkedIn Tiptap and ProseMirror composers, comments, and replies.
  • Package Boundary Topology: Re-architected project structure into a clean /src/ production bundle.
  • Production Code Hygiene: Stripped all debug console logs for zero runtime overhead.

Security & Privacy

  • Zero Elevated Permissions: Declares strictly single-host access (https://www.linkedin.com/*) with no storage, tabs, or broad web request permissions.
  • 100% On-Device Execution: Operates entirely offline with zero remote telemetry or tracking scripts.
