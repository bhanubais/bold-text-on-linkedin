# Skill: Chrome Web Store ASO (App Store Optimization)

## Purpose
Optimize the Chrome Web Store listing for discoverability, conversion, and trust.

## Store Listing Anatomy

### Short Description (≤132 characters)
- Must contain primary keyword.
- Clear value prop in one sentence.
- Example: "Add bold text formatting to LinkedIn posts with Ctrl+B. Select, bold, done."

### Detailed Description
- Lead with the problem (LinkedIn doesn't support Ctrl+B natively).
- Follow with the solution (this extension fixes that, in one shortcut).
- Bullet the features clearly.
- End with trust signals: open source (if applicable), minimal permissions, no data collection.
- Target keywords: LinkedIn bold, bold text LinkedIn, LinkedIn formatting, Ctrl B LinkedIn.

### Screenshots (1280×800 or 640×400)
- Screenshot 1: Hero — show the value prop in action (before/after bold).
- Screenshot 2: How it works — select → Ctrl+B → done.
- Screenshot 3: Trust — minimal permissions, lightweight.
- Max 5 screenshots. Each must be self-explanatory without reading the description.

### Category
- Primary: Productivity
- Secondary: Social & Communication

### Privacy
- Privacy policy URL is REQUIRED to avoid "Proceed with caution."
- Data use disclosure: "This extension does not collect, store, or transmit any user data."
- Select "No" for all data collection categories in the CWS developer dashboard.
