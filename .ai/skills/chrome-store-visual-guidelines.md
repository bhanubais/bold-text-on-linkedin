# Skill: Chrome Web Store Visual Guidelines

## Purpose
Ensure all visual assets meet Chrome Web Store requirements and brand standards.

## Required Assets

### Icons
| Size | Use | Format |
|---|---|---|
| 16×16 px | Toolbar (favicon size) | PNG, transparent background |
| 32×32 px | Toolbar (2x/Retina) | PNG, transparent background |
| 48×48 px | Extensions page | PNG, transparent background |
| 128×128 px | Chrome Web Store tile | PNG, transparent background |

### Store Screenshots
- Dimensions: 1280×800 or 640×400 px
- Format: PNG or JPEG
- Max 5 screenshots
- No excessive whitespace, no mobile device frames
- Must be actual product screenshots or annotated mockups

### Promotional Tiles (Optional but Recommended)
- Small: 440×280 px
- Large: 920×680 px
- Marquee: 1400×560 px

## Brand System (LinkedIn Rich Text Shortcuts)
- Primary Color: LinkedIn Blue (#0A66C2)
- Accent Color: Dark Navy (#1B1F23)
- Background: Light Blue Gradient (#E8F4FD → #FFFFFF)
- Typography: System sans-serif (Inter, SF Pro, or Segoe UI)
- Icon Style: 3D keycap aesthetic (matching existing icon)
