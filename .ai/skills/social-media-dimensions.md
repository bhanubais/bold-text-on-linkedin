# Skill: Social Media Dimensions

## Purpose
Ensure all social media creatives are correctly sized for each platform.

## LinkedIn
| Asset | Dimensions | Aspect Ratio |
|---|---|---|
| Single image post | 1200×1200 px | 1:1 |
| Landscape post | 1200×627 px | 1.91:1 |
| Portrait/carousel | 1080×1350 px | 4:5 |
| Company logo | 300×300 px | 1:1 |
| Banner | 1584×396 px | 4:1 |
| Article cover | 1280×720 px | 16:9 |

## Twitter/X
| Asset | Dimensions | Aspect Ratio |
|---|---|---|
| Single image | 1200×675 px | 16:9 |
| Card image | 800×418 px | 1.91:1 |
| Profile | 400×400 px | 1:1 |
| Header | 1500×500 px | 3:1 |
